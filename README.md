# Blinkit Sales Performance Dashboard – Power BI

This project is an interactive **Power BI dashboard** built using Blinkit sales data. It provides a clear view of total sales, item performance, outlet behavior, customer ratings, and overall business trends. The dashboard includes slicers, KPIs, and dynamic visuals to enable easy exploration and deeper insights.

---

## 🔍 Dashboard Features

### **Key KPIs**
- **$1.20M Total Sales**  
- **$141 Average Sales**  
- **8523 Total Items**  
- **3.9 Average Rating**

### **Interactive Filters**
- Outlet Location Type  
- Outlet Size  
- Item Type  

### **Visuals Included**
- **Sales Over Time (2010–2022)**  
- **Outlet Size Distribution (Small, Medium, High)**  
- **Item Type Sales Breakdown**  
- **Fat Content Comparison (Low Fat vs Regular)**  
- **Outlet Location Ranking (Tier 1–3)**  
- **Outlet Type Summary Table**  
- **Total Sales by Fat Content**

---

## 📊 Key Insights
- Regular fat items generate **higher total sales** than low-fat items.  
- **Supermarket Type 1** contributes the most to total revenue.  
- Tier 3 outlets show the **highest overall sales**.  
- Fruits, snacks, and household goods are among the **top-performing categories**.  
- Sales peaked around **2018–2019**, indicating strong growth during this period.
